# RPCS-LLC

RPCS public-facing brochure website for GitHub Pages.

## Pages

- `index.html` - Home
- `services.html` - Service portfolio
- `industries.html` - Industry focus
- `methodology.html` - Delivery approach
- `case-studies.html` - Outcomes and examples
- `about.html` - Company profile
- `insights.html` - Thought leadership summaries
- `contact.html` - Contact details and CTA

## Shared Assets

- `assets/styles.css` - Global design system and responsive layout
- `assets/main.js` - Mobile navigation toggle, active nav state, and footer year

## GitHub Pages Notes

- Keep all pages at the repository root for simple static hosting.
- Update contact details in page content and footers as needed.
- `CNAME` is retained for custom domain mapping.
